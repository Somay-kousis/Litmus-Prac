# Litmus-Prac

Two practice builds with LangGraph agents.

- [`Cars`](Cars): DriveMatrix, a car spec comparison site whose agent turns horsepower, torque and battery numbers into what they mean on the road.
- [`Clothes`](Clothes): Aura Styling, a wardrobe tracker with a stylist agent that remembers your profile and past conversations.

Each folder has its own README and setup.
